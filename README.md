# Examen Final – Programación Web

Felipe Álvarez Valle

Aplicación web en Flask con un menú y dos ejercicios:

- **Ejercicio 1:** calcula el total de una compra de tarros de pintura ($9.000 cada uno). Aplica 15 % de descuento entre 18 y 30 años, 25 % sobre 30 años y ningún descuento bajo 18.
- **Ejercicio 2:** inicio de sesión con dos usuarios registrados: juan (administrador) y pepe (usuario).

## Cómo ejecutarlo

```
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python main.py
```

Luego abrir http://127.0.0.1:5000
